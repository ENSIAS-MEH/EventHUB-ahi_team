# EventHub - Découverte d'événements entre jeunes

> Plateforme sociale web permettant aux jeunes de découvrir, partager et participer à des événements près de chez eux.


# A propos du projet

**EventHub** est une application développée dans le cadre du module **"Plate-formes de développement"** (AHI - équipe). Le projet répond au thème : *"Applications sociales et interactives pour les jeunes"*.


# Problématique

Actuellement, les jeunes doivent consulter plusieurs sources pour trouver des événements :
- **Instagram** : stories et posts éphémères
- **Facebook Events** : peu utilisé par les moins de 25 ans
- **WhatsApp** : bouche-à-oreille limité aux groupes existants
- **Affiches** : souvent vues trop tard


**Conséquences** : 

- Beaucoup d'événements sont ratés par manque d'information
- Difficulté à sortir seul quand les amis sont occupés
- Absence de retours d'expérience fiables
